Implementation

How it's
put together.

A short tour of the moving parts. Each module is written from scratch, lives in its own file, and shares a single interface so components are interchangeable.

Components

The stack.

Three trainable networks and a forward-process module. The weight converter lets us load official Stable Diffusion 1.4 checkpoints into the same classes used for training.

VAE
Encoder, decoder, KL bottleneck.
A convolutional encoder/decoder pair with a Gaussian latent bottleneck. The U-Net operates entirely in this latent space, so the VAE is the bridge between pixel-space images and the diffusion target.
U-Net
Configurable backbone with cross-attention.
Residual blocks at four resolutions, cross-attention layers consuming text embeddings, and a flash-attention path. Channel multipliers, attention levels, and head counts are all set from a config dict.
CLIP text encoder
Tokenizer + transformer, our wrapper.
A CLIP text transformer with our own tokenizer wrapper that matches the HuggingFace state-dict layout, so pretrained text encoders drop in without modification.

Sampling

Solvers & schedules.

Inference is decoupled from training. The same trained U-Net runs under any sampler/schedule combination, exposed as command-line flags on models/generate.py.

Samplers
DDPM · DDIM · Euler-A · Heun · DPM++ 2M.
Stochastic and deterministic options behind one interface. Each takes the U-Net, the noise schedule, a target shape, and a step count.
β schedules
Linear, scaled-linear, cosine, quadratic.
Selected per run. The Karras σ schedule can be layered on top for samplers that operate in σ-space, shifting more compute toward the low-noise end.
Guidance
CFG with optional rescale.
Classifier-free guidance with the rescale trick from Lin et al. (2024) as a single flag, to recover dynamic range at high guidance scales without giving up prompt adherence.

Training

Three-stage loop.

The VAE and CLIP encoders only need to be evaluated once per image. Caching their outputs to disk leaves the U-Net step UNet-bound on a single consumer GPU.

1 · Precompute
Cache latents and embeddings.
runs/compute_latents.py writes (latents, conds) tensors per sample. Re-used across every training run after.
2 · Train VAE
Reconstruction + KL.
runs/train_vae.py trains the bottleneck against a weighted MSE + KL objective. Hyperparameters live at the top of the script.
3 · Train U-Net
YAML-configured, latent-space.
runs/train_unet.py consumes cached pairs and steps the U-Net against the diffusion objective. β schedule, model dims, and logging cadence are set in a config file.
